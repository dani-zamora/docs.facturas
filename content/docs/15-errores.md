## Errores frecuentes

- **Cuadre de totales:** la suma de líneas no coincide con `totals`.
- **NIF inválido:** formato o dígito de control incorrecto.
- **Impuestos:** tipo o base imponible fuera de rango.

## FAQ

- **¿Sandbox tiene validez legal?** No. Los envíos a AEAT en sandbox son de prueba.
- **¿Qué pasa si supero el límite del plan?** Las peticiones devuelven `402` hasta renovar o hacer upgrade.
- **¿Cómo migrar de sandbox a producción?** Cambiar la base URL y usar una API key de producción.
