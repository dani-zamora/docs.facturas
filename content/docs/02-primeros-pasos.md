## Alta

La API publica v1.1 opera sobre la empresa asociada a la API key. Consulta la empresa activa con `GET /api/v1.1/company`.

## Generar una API key

Desde `/app/settings/api-keys`. Formato `ak_<kid>:<secret>`, header `X-API-Key`.
