## Glosario

| Término | Definición |
|---|---|
| **NIF** | Número de Identificación Fiscal |
| **IVA** | Impuesto sobre el Valor Añadido |
| **IGIC** | Impuesto General Indirecto Canario |
| **TAI** | Territorio de Aplicación del Impuesto |
| **Rectificativa** | Factura que corrige total o parcialmente una factura emitida |
| **Simplificada** | Factura sin identificación del destinatario (ticket) |
| **VeriFactu** | Sistema de verificación de facturas de la AEAT |
| **SII** | Suministro Inmediato de Información |
| **Facturae** | Formato XML de factura electrónica español |
| **UBL** | Universal Business Language (estándar europeo EN 16931) |
| **XAdES** | Firma electrónica avanzada XML |
| **QR AEAT** | Código QR de verificación de factura emitido por la AEAT |
